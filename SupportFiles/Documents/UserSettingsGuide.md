# ED_ENHANCED_T16000 - USER SETTINGS GUIDE  

- Open the TARGET Script Editor program.  
- Open ED_BASIC_T16000.tmc  
- Find the setting for YAWDeviceOverride  
  * DISABLED by default - The YAWDevice will be set to either Joystick Twist, Throttle Paddles  or Rudder Pedals, if found  
  * Set to ENABLED, then set YAWDevice manually to your preferred controller (JSTwist, THRPaddles or RudderPedals)  
- Always save, then compile the script every time you make any changes!
- More settings are described in the CUSTOMISATION.md file
